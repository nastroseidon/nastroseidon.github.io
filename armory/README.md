# Sanctuary Armory (web edition 0.9.0)

Built from the Sanctuary Armory project with `node scripts/build_web.mjs`. Don't edit these files by hand; rebuild instead.
Open https://nicksmith.app/armory/ on the iPhone and use Share → Add to Home Screen.
Third-party: tesseract.js and its English model (Apache-2.0, see vendor/tesseract/). Item names and game text belong to Blizzard Entertainment; build data is read live from Maxroll.
